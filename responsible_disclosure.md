# Security Disclosures

This repository is maintained by [Zec.rocks](https://zec.rocks). Please report security
vulnerabilities in this SDK privately through GitHub's
[private vulnerability reporting](https://github.com/zecrocks/zcash-android-wallet-sdk/security/advisories/new)
for this repository. Do not open public issues for security problems.

We will acknowledge receipt, work with you on a coordinated fix and release, and credit you
if you wish.

Vulnerabilities in upstream dependencies should also be reported to their maintainers:
for librustzcash and Orchard, follow the Zcash security disclosure process at
https://z.cash/support/security/.
